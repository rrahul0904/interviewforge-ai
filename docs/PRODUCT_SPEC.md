# Product specification

## Primary personas

- Candidate with a specific company interview in 1–4 weeks
- Candidate exploring companies and roles
- Community contributor sharing interview experiences
- Content moderator / intelligence analyst
- Operator managing subscriptions, cost and source quality

## Core journeys

### Discover
Home → company / track → filtered question bank → question detail.

### Prepare
Question → practice workspace → hints / AI coach → run/submit → result → next recommended question.

### Personalize (next phase)
Upload resume + paste job description + select company → gap model → adaptive preparation plan → mock interview room.

### Contribute
Forum → create interview experience → company/role/round tags → moderation → searchable community intelligence.

## Tracks

- Coding
- SQL
- System Design
- ML System Design
- Object-Oriented Design
- Behavioral (planned)

## Differentiators

1. Freshness: when was a question actually reported?
2. Evidence confidence: how many independent reports support the attribution?
3. Provenance: where did intelligence come from, and may we legally retain it?
4. Personalization: what should *this candidate* practice next?
5. Outcome loop: practice telemetry improves recommendations.
