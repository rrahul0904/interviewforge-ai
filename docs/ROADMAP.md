# Delivery roadmap

## Phase 0 — foundation (this repository baseline)
- architecture and domain model
- navigable premium UI
- demo question/company/forum data
- AI + execution provider contracts
- ingestion normalization primitives
- persistence schema
- CI + local infrastructure

## Phase 1 — durable product core
- Auth.js or Clerk authentication
- Postgres-backed repositories replacing demo data
- admin seed/import tooling
- saved questions, attempts and progress
- full-text search + cursor pagination
- forum create/reply/vote flows with moderation

## Phase 2 — real practice engine
- isolated execution vendor integration
- multi-language starter code and test harnesses
- SQL sandbox
- submission history and acceptance metrics
- structured AI hints / debugging / follow-ups

## Phase 3 — interview intelligence pipeline
- compliant source connectors
- raw document registry
- extraction jobs
- semantic dedupe + canonical matching
- analyst moderation console
- confidence and freshness scoring

## Phase 4 — monetization
- Stripe checkout + customer portal
- entitlements and usage limits
- referral ledger
- AI/execution cost accounting
- operator finance dashboard

## Phase 5 — candidate intelligence
- resume + JD ingestion
- skill evidence graph
- company-specific risk analysis
- adaptive curriculum
- voice/text mock interview rooms
- post-interview scorecards and next-best-action engine

## Phase 6 — scale and certification
- load tests
- abuse/rate limiting
- SLO dashboards and alerts
- security review
- backup/restore drills
- accessibility and responsive certification
- production deployment + smoke tests
